---

MDI の原稿は `{親文字|ルビ}` のように書き、出力時に各投稿先の記法へ変換する。このページは、MDI のソース記法と、[SYNTAX.md の TXT 書き出し対応表](https://github.com/illusions-lab/MDI/blob/main/SYNTAX.md)が契約にしている公式記法を並べる。

## ルビ、縦中横、傍点

| | ルビ | 縦中横 | 傍点 |
| --- | --- | --- | --- |
| MDI | `{東京\|とうきょう}`。分割は `{東京\|とう.きょう}` | `^12^` | `[[em:それ]]` |
| でんでんマークダウン | `{電子出版\|でんししゅっぱん}`。分割は `\|` 区切りの `{電子出版\|でん\|し\|しゅっ\|ぱん}` | `^53^` | 専用記法はない。縦書き時の `*強調*` をコンバーターが圏点で描く |
| 小説家になろう | `｜東京《とうきょう》`。親文字とルビは各 1〜10 字。`&"<>` は不可 | 記法はなく、中の文字だけになる | 一字ずつの圏点ルビ `｜そ《・》｜れ《・》` |
| カクヨム | `｜東京《とうきょう》`。親文字 20 字、ルビ 50 字まで | 記法はなく、中の文字だけになる | `《《それ》》` |
| 青空文庫 | `｜東京《とうきょう》` | `12［＃「12」は縦中横］` | `［＃傍点］それ［＃傍点終わり］` |

でんでんマークダウンのルビと縦中横は[公式シンタックス](https://conv.denshochan.com/markdown)の通り。なろうは[ルビ](https://syosetu.com/helpcenter/helppage/helppageid/42/)と[傍点](https://syosetu.com/helpcenter/helppage/helppageid/43/)、カクヨムは[記法ヘルプ](https://kakuyomu.jp/help/entry/notation)、青空文庫は[入力マニュアル](https://www.aozora.gr.jp/aozora-manual/index-input.html)と[注記一覧](https://www.aozora.gr.jp/annotation/)に従う。

MDI の分割ルビはドットで区切る。でんでんマークダウンの熟語ルビは縦棒で区切る。区切りの数が親文字と合わないとき、どちらもグループルビに戻る。

## 改ページと縦書き

MDI の改ページは `[[pagebreak]]`、見開きは `[[pagebreak:left]]` と `[[pagebreak:right]]`。文書全体の縦書きは front matter の `writing-mode: vertical` で、レンダラーが `writing-mode: vertical-rl` を付ける。

でんでんマークダウンの改ページは、`=` を3つ以上並べた行による HTML ファイルの分割である。公式シンタックスに、文書全体の縦書きを宣言する記法はない。

なろうとカクヨムのプレーンテキストに、改ページと文書全体の縦書きの記法はない。MDI から書き出すときは改ページを落とし、縦中横は中の文字だけにする。青空文庫は `［＃改ページ］`、`［＃改丁］`、`［＃改見開き］` を使う。

## 割注

MDI は `[[warichu:注記]]` と書く。なろうとカクヨムには対応する記法がなく、書き出しは中の文字だけになる。青空文庫は `［＃割り注］注記［＃割り注終わり］`。でんでんマークダウンの公式シンタックスに割注の記法はない。
